@q 반도체 패키지의 역할은 무엇입니까?
@why 현직자가 꼽은 PKG 단골 질문입니다. A!SK에서도 "직무기술서 수준의 개념"을 묻는다는 후기가 있습니다.
@p 네 가지: 기계적 보호 / 전기적 연결 / 기계적 연결 / 열 방출
@p 최근에는 성능 자체를 결정
@m 패키지의 역할은 네 가지로 정리할 수 있습니다.

첫째 **기계적 보호**입니다. 깨지기 쉬운 실리콘 칩을 EMC 같은 재료로 감싸 외부 충격과 습기, 오염에서 지킵니다. 둘째 **전기적 연결**입니다. 칩의 미세한 패드를 범프나 와이어, 기판 배선을 통해 시스템에 연결하고 전원을 공급합니다. 셋째 **기계적 연결**로, 칩을 기판이나 보드에 안정적으로 고정합니다. 넷째 **열 방출**입니다. 동작 중 생기는 열을 밖으로 빼 줍니다.

최근에는 여기에 더해 패키지가 **성능 자체를 결정하는 역할**로 커졌다고 생각합니다. HBM처럼 칩을 수직으로 쌓아 TSV로 연결하면 미세화 없이도 용량과 대역폭을 높일 수 있기 때문입니다.
@k 보호 :: 보호|충격|습기
@k 전기적 연결 :: 전기|연결|범프|와이어|전원
@k 기계적 연결 :: 고정|기계적 연결|지지
@k 열 방출 :: 열|방열|방출
@k 최근 역할 :: 성능|HBM|TSV|적층
@f 네 가지 중 HBM에서 가장 어려워진 것은 무엇입니까? || 열 방출. 적층으로 열이 빠져나갈 길이 길어짐.

@sec 90
@q 패키지 공정의 순서를 설명해 보세요.
@why "패키징 공정이란?"은 현직자가 꼽은 단골 질문입니다. 순서를 외우는 것보다 각 단계가 왜 있는지를 한마디씩 붙일 수 있어야 합니다.
@p 컨벤셔널: 백 그라인딩 → 절단 → 다이 어태치 → 인터커넥션 → 몰딩 → 마킹 → 솔더 볼 → 싱귤레이션
@p TSV 제품은 흐름이 다름
@p 본인 관심 공정으로 마무리
@m 서브스트레이트 타입의 컨벤셔널 패키지를 기준으로 말씀드리겠습니다.

먼저 웨이퍼 뒷면을 갈아 두께를 맞추는 **백 그라인딩**, 칩 단위로 자르는 **웨이퍼 절단**, 양품 칩을 기판에 붙이는 **다이 어태치**를 합니다. 다음으로 칩과 기판을 전기적으로 잇는 **인터커넥션**, 즉 와이어 본딩이나 플립 칩 본딩을 하고, EMC로 감싸는 **몰딩**을 합니다. 이후 **마킹**, **솔더 볼 마운팅**, 개별 패키지로 자르는 **싱귤레이션**을 거쳐 패키지 테스트로 넘어갑니다.

HBM 같은 TSV 제품은 흐름이 다릅니다. 웨이퍼 상태에서 TSV와 범프를 만들고, 캐리어에 임시로 붙인 뒤 뒷면을 갈아 TSV를 노출시키고, **칩을 쌓은 다음 몰딩**합니다.

제가 관심 있는 것은 이 가운데 **적층 이후 갭을 채우는 몰딩 공정**입니다.
@k 앞 단계 :: 백 그라인딩|그라인딩|절단|다이싱|소우
@k 접합 :: 다이 어태치|와이어|플립|인터커넥션|본딩
@k 몰딩 :: 몰딩|EMC
@k 뒤 단계 :: 마킹|솔더 볼|싱귤레이션
@k TSV 흐름 :: TSV|적층|캐리어|쌓
@f 백 그라인딩을 하면 왜 웨이퍼가 휩니까? || 연마 후 잔류 응력. 얇을수록 심해져서 테이프와 링 프레임으로 잡아 준다.
@f 컨벤셔널 패키지와 웨이퍼 레벨 패키지의 차이는 무엇입니까? || 칩으로 먼저 자른 뒤 패키징 vs 웨이퍼 상태에서 공정을 진행한 뒤 절단.

@sec 120
@q EMC는 무엇으로 이루어져 있고, 조성에 따라 특성이 어떻게 달라집니까?
@why 현직자가 꼽은 단골 질문이면서, 화학·고분자 전공과 지원서 내용에 가장 가까운 질문입니다. 여기서 강점을 보여 줘야 합니다.
@p 구성: 열경화성 에폭시 수지 + 실리카 필러 + 경화제·첨가제
@p 필러 함량↑ → CTE↓, 흡습↓, 방열↑ / 점도↑, 충진성↓
@p 필러 크기·형상
@p 수지·경화제 → Tg, 탄성률, 경화 속도, 접착력
@p 결론: 균형 잡기
@m EMC는 **열경화성 에폭시 수지**에 **무기 필러인 실리카**를 섞고 경화제와 첨가제를 더한 복합 재료입니다. 열을 받으면 수지가 3차원 그물 구조로 가교되어 굳습니다.

조성에서 가장 큰 변수는 **필러**입니다. 실리카는 열팽창계수가 낮아서 **필러 함량을 높이면 EMC의 CTE가 실리콘 칩에 가까워져 휨과 응력이 줄고**, 흡습도 줄어듭니다. 열전도가 높은 필러를 쓰면 방열도 좋아집니다. 반대로 **점도가 올라가 유동성이 떨어지기 때문에** 좁은 틈을 채우기 어려워지고 Void 위험이 커집니다. 그래서 **필러의 함량, 크기 분포, 형상**을 함께 설계합니다.

수지와 경화제는 **유리전이온도(Tg), 탄성률, 경화 속도, 접착력**을 좌우합니다. Tg를 넘으면 열팽창이 크게 늘기 때문에 Tg 설계도 휨에 직접 영향을 줍니다.

결국 EMC 설계는 **충진성, 휨, 방열, 신뢰성 사이의 균형 잡기**라고 이해하고 있습니다.
@k 구성 :: 에폭시|수지|레진
@k 필러 :: 필러|실리카|filler
@k 경화 :: 경화|가교|열경화
@k CTE·휨 :: CTE|열팽창|휨|warpage
@k 유동성 :: 점도|유동|충진
@k Tg·탄성률 :: Tg|유리전이|탄성률|모듈러스
@f 그러면 필러 함량을 계속 올리면 되지 않습니까? 왜 한계가 있습니까? || 점도 급상승 → 충진 불량·Void, 탄성률 상승 → 응력 증가 가능.
@f 큰 입자와 작은 입자를 섞어 쓰는 이유는 무엇입니까? || 큰 입자 사이를 작은 입자가 메워 충진 밀도를 높이면서 점도 상승을 억제. 좁은 갭에는 최대 입경 제한이 필요.
@f 배터리 합제의 입자와 EMC의 필러는 어떻게 다릅니까? || 본인 경험과 연결. 차이(EMC는 수지가 녹아 흐르고 굳는다)를 먼저 말하기.

@q 트랜스퍼 몰딩과 컴프레션 몰딩의 차이는 무엇입니까? 왜 컴프레션 방식이 늘고 있습니까?
@why 지원서에 Compression Molding을 여러 번 썼기 때문에 거의 확실히 나옵니다. 지원서에서는 '면 전체 수직 가압'으로만 설명했는데, 핵심 차이는 'EMC가 흐르는 거리'입니다.
@p 트랜스퍼: 녹여서 금형으로 흘려보냄
@p 컴프레션: 금형에 미리 넣고 그 자리에서 눌러 성형
@p 차이의 핵심: 흐르는 거리
@p 추세: 얇게, 높게 쌓고, 크게
@m **트랜스퍼 몰딩**은 EMC 태블릿을 가열·가압해 녹인 뒤, 통로를 따라 금형 안으로 **흘려보내 채우는** 방식입니다. 오래 써 온 방식이지만 EMC가 먼 거리를 흐르기 때문에, 칩과 패키지 윗면 사이 간격이 좁아지거나 기판이 커지면 **충진이 어려워집니다**.

**컴프레션 몰딩**은 금형에 가루나 과립, 액상 EMC를 **미리 넣어 녹인 뒤 그 자리에서 눌러 성형**합니다. **EMC가 흐르는 거리가 짧아서** 얇은 패키지, 고적층, 대형 기판이나 웨이퍼 몰딩에서도 충진이 안정적이고, 유동 때문에 생기는 와이어 쓸림이나 Void가 줄어듭니다.

적층 수는 늘고 패키지는 얇아지며 기판은 커지는 추세라서 컴프레션 방식의 비중이 커지고 있다고 이해하고 있습니다. 대신 **EMC 투입량과 두께 균일도, 진공 조건**의 관리가 중요해진다고 생각합니다.
@k 트랜스퍼 :: 트랜스퍼|태블릿|흘려|통로
@k 컴프레션 :: 컴프레션|압축|미리|눌러
@k 핵심 차이 :: 거리|유동|흐르
@k 적용 :: 얇|적층|대형|웨이퍼
@k 관리 항목 :: 투입량|두께|균일|진공
@f 컴프레션 몰딩의 단점이나 어려운 점은 무엇입니까? || 투입량 편차가 곧 두께 편차, 진공·이형 필름 관리 등. 공개 자료에서 확인한 범위까지만, 나머지는 "배우겠다".
@f EMC의 형태(태블릿·과립·액상·필름)는 어떻게 구분해 씁니까? || 태블릿 = 트랜스퍼, 가루·과립 = 압축·대형 웨이퍼 몰딩, 액상 = 성형이 어려운 웨이퍼 몰딩, 필름 = 팬아웃·대면적.

@sec 120
@q MR-MUF와 TC-NCF를 비교해서 설명해 보세요.
@why SK하이닉스 HBM 경쟁력의 핵심 공정입니다. PKG개발 지원자라면 반드시 준비해야 하고, 현직자도 단골로 꼽았습니다.
@p TC-NCF: 필름 + 한 장씩 열압착
@p MR-MUF: 한 번에 리플로우 + 액상 EMC 충진
@p 장단점: 생산성·방열 / 휨·갭 충진
@p 어드밴스드 MR-MUF
@m 둘 다 TSV로 쌓은 칩 사이를 접합하고 채우는 방식입니다.

**TC-NCF**는 칩 사이에 비전도성 필름을 미리 붙이고, 칩을 한 장씩 **열과 압력으로 눌러** 범프 접합과 갭 충진을 동시에 합니다. 휜 칩도 눌러서 붙일 수 있지만, 한 장씩 가압하기 때문에 **생산성이 낮고** 필름 재료의 열전도가 상대적으로 낮습니다.

**MR-MUF**는 칩을 쌓은 뒤 **매스 리플로우로 범프를 한 번에 접합**하고, 칩 사이에 **액상 EMC를 넣어 굳힙니다**. 한 번에 처리해서 **생산성이 높고**, **방열에 유리**합니다. 대신 누르는 힘이 약해서 **얇은 칩의 휨 제어**가 어렵고, 좁은 갭을 **Void 없이 채우는 것**이 과제입니다.

SK하이닉스는 12단 HBM3에서 휨 제어 기술과 신규 EMC를 적용한 **어드밴스드 MR-MUF**로 이 한계를 넘었고, 당시 뉴스룸에서 생산성 약 3배, 열 방출 약 2.5배 향상을 밝힌 것으로 알고 있습니다.
@k TC-NCF :: NCF|필름|열압착|TC
@k MR-MUF :: MR-MUF|리플로우|액상|MUF
@k 생산성 :: 생산성|한 번에|한 장씩
@k 방열 :: 방열|열전도|열 방출
@k 과제 :: 휨|갭|void|보이드
@k 어드밴스드 :: 어드밴스드|advanced|12단|신규 EMC
@f 경쟁사는 왜 TC-NCF를 씁니까? || 얇은 칩을 눌러 휨을 잡기 쉽고 미세 피치에 유리하다는 장점. 타사 비하 금지, 장단점으로만.
@f MR-MUF에서 Void가 생기면 어떤 문제가 됩니까? || 방열 경로 차단, 범프 주변 지지 부족 → 신뢰성(TC) 불량, 흡습 경로.
@f 16단, 20단으로 가면 MR-MUF로 계속 갈 수 있습니까? || 칩이 더 얇아져 휨·갭 충진이 더 어려워짐 → 고도화와 하이브리드 본딩 병행. 단정하지 말고 "공개 발표 기준으로는".

@sec 90
@q 하이브리드 본딩은 무엇이고, 왜 필요하며, 무엇이 어렵습니까?
@why 최근 트렌드 질문의 단골 소재입니다. 장점만 말하지 말고 어려운 점과 도입 시점에 대한 균형 잡힌 시각을 보여 주세요.
@p 정의: 범프 없이 구리-구리 직접 접합
@p 장점: 두께, 피치, 열저항
@p 어려움: 평탄도, 파티클, 정렬, 수율
@p 전망: 단계적 도입
@m 하이브리드 본딩은 **범프 없이 구리와 구리, 절연막과 절연막을 직접 붙이는** 접합 방식입니다. 범프와 그 사이를 채우는 재료가 없어지기 때문에 **같은 높이에 더 많이 쌓거나 칩을 더 두껍게 가져갈 수 있고**, 연결 간격을 더 좁힐 수 있으며, **열저항도 줄어듭니다**.

어려운 점은 **표면 품질**입니다. 접합면이 매우 평탄해야 해서 CMP를 정밀하게 제어해야 하고, **미세 파티클 하나가 접합 Void**가 되기 때문에 전공정 수준의 청정도가 필요합니다. 정렬 정밀도와 수율, 장비 투자 부담도 큽니다.

그래서 MR-MUF를 한 번에 대체하기보다 **적층 단수와 두께 요구가 한계에 이르는 세대부터 단계적으로 도입**될 것으로 이해하고 있습니다. SK하이닉스도 올해 학회에서 MR-MUF 대비 **열저항을 약 35% 낮출 수 있다**고 발표한 것으로 알고 있습니다.
@k 정의 :: 범프 없이|직접|구리|Cu
@k 장점 :: 두께|간격|피치|열저항|적층
@k 어려움 :: 평탄|CMP|파티클|청정|정렬
@k 수율·비용 :: 수율|투자|장비
@k 전망 :: 단계적|도입|병행
@f 하이브리드 본딩이 도입되면 몰딩 공정은 없어집니까? || 칩 사이 갭 충진은 줄어도 적층체 보호와 휨 제어를 위한 몰딩·봉지 과제는 남는다고 본다. 단정 금지.

@q Warpage(휨)는 왜 생기고, 어떻게 줄입니까?

@p 원인 2: EMC 경화 수축

@p 대책: 소재 / 구조 / 공정
@p 온도에 따라 방향이 바뀜 → 온도별 측정
@m 휨의 근본 원인은 **재료 간 열팽창계수(CTE) 차이**입니다. 실리콘은 열팽창이 작고 EMC와 기판은 그보다 큽니다. 몰딩은 고온에서 이뤄지기 때문에 상온으로 식는 동안 재료마다 줄어드는 양이 달라서 한쪽으로 휩니다. 여기에 EMC가 굳으면서 부피가 줄어드는 **경화 수축**이 더해집니다. 칩이 얇아지고 면적이 커질수록 휨은 커집니다.

중요한 점은 휨이 **온도에 따라 방향까지 바뀔 수 있다**는 것입니다. 그래서 상온뿐 아니라 리플로우 온도에서의 휨도 함께 봐야 하고, 시뮬레이션으로 예측한 뒤 실측으로 맞춰 가는 방식이 필요하다고 생각합니다.

@q 몰딩 공정에서 Void는 왜 생기고, 어떻게 줄입니까?
@why 지원서에서 입사 후 해결하겠다고 쓴 첫 번째 문제(EMC Void)입니다. 원인을 경로별로 나누고, 원인마다 대책을 짝지어 말하세요.
@p 원인 3경로: 공기 포집 / 충진 미완 / 가스 발생
@p 대책: 진공 / 프로파일 / 소재 선택 / 건조
@p 검출: 초음파·X-ray·단면
@p 본인 경험 연결
@m Void가 생기는 경로는 크게 세 가지로 이해하고 있습니다. 첫째 **공기 포집**입니다. EMC가 흐르는 앞부분이 여러 방향에서 만나거나, 넓은 곳과 좁은 틈의 속도 차이로 좁은 쪽에 공기가 갇힙니다. 둘째 **충진 미완**입니다. 점도가 높거나, 다 채우기 전에 경화가 진행되거나, 필러 입자가 갭에 비해 크면 틈이 남습니다. 셋째 **가스 발생**입니다. 재료가 머금은 수분이나 휘발 성분이 고온에서 기화합니다.

대책은 원인별로 다릅니다. **진공도를 높여** 공기를 미리 빼고, **온도·압력·속도 프로파일**을 조정해 경화 전에 충진이 끝나게 하고, **필러 크기와 점도**가 갭에 맞는 EMC를 고르고, 자재를 **미리 건조**합니다. 검출은 **초음파 검사나 X-ray** 같은 비파괴 검사와 단면 분석으로 한다고 알고 있습니다.

현 직장에서 다룬 **미세 보이드와 수분 관리** 경험이 원인 경로를 추적하는 데 도움이 될 것이라고 생각합니다.
@k 공기 포집 :: 공기|갇|포집|속도 차이
@k 충진 미완 :: 점도|충진|경화|필러
@k 가스 :: 수분|휘발|기화|가스
@k 대책 :: 진공|프로파일|건조
@k 검출 :: 초음파|SAT|X-ray|엑스레이|단면
@k 경험 연결 :: 보이드|수분 관리|경험
