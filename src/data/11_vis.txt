@q 그래프는 두 EMC 소재로 만든 패키지의 온도별 휨을 나타냅니다. 읽을 수 있는 내용과 원인, 대책을 설명해 보세요.
@why 그래프에서 사실을 먼저 읽고, 그다음 원인을 추론하는지 봅니다. 아는 지식을 그래프와 상관없이 늘어놓으면 감점입니다.
@p 축과 범례부터 읽기
@p 사실: 상온에서는 B가 작고, 고온에서는 B가 크다. 방향이 바뀐다
@p 원인 추론: Tg, CTE
@p 영향: 리플로우 시 접합 불량
@p 대책과 추가로 확인할 것
@m 먼저 **그래프에서 읽을 수 있는 사실**입니다. 가로축은 온도, 세로축은 휨입니다. 두 소재 모두 상온에서는 위쪽으로, 온도가 오르면 아래쪽으로 **휨의 방향이 바뀝니다**. 상온에서는 소재 B의 휨이 더 작지만, **고온에서는 B의 휨이 훨씬 커집니다**. 그리고 B는 A보다 **낮은 온도에서 꺾이기 시작**합니다.

**원인**으로는 B의 **유리전이온도(Tg)가 더 낮을 가능성**을 먼저 생각합니다. Tg를 넘으면 EMC의 열팽창이 크게 늘기 때문에, Tg가 낮은 소재는 더 낮은 온도부터 휨이 빠르게 변합니다.

**영향**은 고온 쪽이 더 큽니다. 실장할 때 리플로우 온도에서 휨이 크면 **범프나 솔더 볼의 접합 불량**으로 이어집니다. 상온 값만 보고 B가 더 좋다고 판단하면 안 됩니다.

**대책**은 Tg와 필러 조성을 조정한 소재를 검토하거나, 후경화 조건으로 개선되는지 확인하는 것입니다. 추가로 **두 소재의 Tg와 CTE 데이터**를 확인하고 싶습니다.
@k 사실 읽기 :: 상온|고온|가로축|세로축|방향
@k 비교 :: B|A|더 작|더 크|커집니다
@k 원인 :: Tg|유리전이|열팽창|CTE
@k 영향 :: 리플로우|접합|범프|솔더
@k 대책 :: 필러|후경화|조정|확인

@q 그래프는 EMC의 필러 함량에 따른 열팽창계수(CTE)와 점도의 변화입니다. 무엇을 읽을 수 있고, 최적 함량을 어떻게 정하겠습니까?
@why 트레이드오프를 그래프에서 읽고 판단 기준을 세우는지 봅니다. "가운데가 좋다"가 아니라 기준이 있어야 합니다.
@p 사실: 함량↑ → CTE↓(완만), 점도↑(가파르게)
@p 의미: 휨에는 유리, 충진에는 불리
@p 판단 기준: 충진 한계 안에서 가장 높은 함량
@p 추가 확인 데이터
@m **읽을 수 있는 사실**은 두 가지입니다. 필러 함량이 늘수록 **CTE는 꾸준히 낮아지고**, **점도는 올라가는데 높은 함량에서 급격히 올라갑니다**.

**의미**는 트레이드오프입니다. CTE가 낮아지면 실리콘과의 열팽창 차이가 줄어 **휨과 응력에 유리**하지만, 점도가 오르면 **좁은 갭의 충진이 어려워져 Void 위험**이 커집니다.

**최적 함량**은 가운데 값이 아니라 **기준으로 정해야** 합니다. 충진성은 반드시 만족해야 하는 조건이므로, 먼저 갭을 Void 없이 채울 수 있는 **점도의 상한**을 실험으로 정하고, 그 한계 안에서 **가장 높은 함량**을 고르겠습니다. 그래프에서는 점도가 급격히 오르기 직전 구간이 후보입니다.

추가로 **필러 크기 분포를 바꾸면 같은 함량에서 점도를 낮출 수 있는지**, 그리고 열전도 데이터를 함께 보고 싶습니다.
@k 사실 읽기 :: CTE|점도|낮아|올라|급격
@k 의미 :: 트레이드|휨|충진|void|보이드
@k 판단 기준 :: 상한|기준|한계|가장 높은
@k 추가 확인 :: 크기 분포|열전도|추가

@q 그래프는 어떤 공정의 두께 측정값 관리도입니다. 이 공정은 정상입니까? 무엇을 하겠습니까?
@why 2지망 양산기술을 겨냥한 문항입니다. "한계 안이니까 정상"이라고 답하면 틀립니다.
@p 사실: 모든 점이 관리 한계 안
@p 그러나 뒤쪽 점들이 연속으로 상승
@p 판단: 이상 신호, 곧 한계를 벗어날 수 있음
@p 조치: 원인 확인, 변화 시점에 바뀐 것
@m **사실부터** 말씀드리겠습니다. 모든 점이 위아래 관리 한계 안에 있습니다. 하지만 **뒤쪽의 점들이 연속해서 올라가고 있고**, 마지막 점은 위쪽 한계에 가까워졌습니다.

그래서 저는 이 공정을 **정상이라고 보지 않습니다**. 관리도는 한계를 벗어난 점뿐 아니라 **한쪽으로 이어지는 경향**도 이상 신호로 봅니다. 이대로면 몇 번 안에 한계를 벗어날 가능성이 높습니다.

**조치**는 세 가지입니다. 먼저 상승이 **시작된 시점에 바뀐 것**을 찾습니다. 자재 로트 교체, 부품 마모, 점검 이후 경과 시간 같은 것입니다. 다음으로 **측정 자체의 문제는 아닌지** 확인합니다. 그리고 원인이 확인될 때까지 **측정 빈도를 높여** 한계를 벗어나기 전에 대응합니다.

서서히 오르는 모양은 **소모품의 마모나 누적 오염처럼 시간에 따라 변하는 원인**을 먼저 의심하게 합니다.
@k 사실 읽기 :: 한계 안|관리 한계|모든 점
@k 경향 :: 연속|상승|올라|경향
@k 판단 :: 정상이 아니|이상|벗어날
@k 조치 :: 바뀐|시점|측정|빈도
@k 원인 추정 :: 마모|오염|로트|시간

@q 그래프는 접합 1회당 수율이 다른 세 경우에 대해, 적층 단수에 따른 적층 수율을 계산한 것입니다. 무엇을 읽을 수 있습니까?
@why 누적 수율의 개념을 이해하는지 봅니다. HBM에서 접합 수율과 양품 칩 선별이 왜 중요한지로 연결해야 합니다.
@p 사실: 단수가 늘수록 수율 하락, 접합 수율이 낮을수록 가파름
@p 원리: 곱셈 (누적)
@p 의미: 작은 차이가 고단에서 크게 벌어짐
@p 대책: 접합 수율 향상, 양품 칩만 적층, 휨 관리
@m **읽을 수 있는 사실**은 두 가지입니다. 적층 단수가 늘수록 수율이 떨어지고, **접합 1회당 수율이 조금만 낮아도 고단에서는 차이가 크게 벌어집니다**. 8단에서는 세 선의 차이가 작지만 16단 이상에서는 눈에 띄게 벌어집니다.

**원리**는 곱셈입니다. 한 번의 접합이 모두 성공해야 전체가 양품이기 때문에, 적층 수율은 **1회 수율을 단수만큼 곱한 값**이 됩니다.

**의미**는 적층 단수가 늘수록 **접합 한 번의 완성도가 훨씬 더 중요해진다**는 것입니다. 낮은 단수에서는 괜찮던 수율이 고단 제품에서는 받아들일 수 없는 수준이 됩니다.

**대책**은 세 방향입니다. 접합 불량의 원인인 **휨과 범프 높이 편차를 줄이고**, 검사를 통과한 **양품 칩만 쌓고**, 불량이 생긴 층을 빨리 찾아내는 검사를 두는 것입니다. HBM에서 패키징 수율이 제품 원가와 공급량을 좌우하는 이유라고 생각합니다.
@k 사실 읽기 :: 단수|떨어|벌어
@k 원리 :: 곱|누적
@k 의미 :: 중요|고단|접합
@k 대책 :: 휨|양품|검사|범프
