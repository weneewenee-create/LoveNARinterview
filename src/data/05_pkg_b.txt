@q 패키지에서 열 관리는 왜 중요하고, 어떤 방법이 있습니까?
@why 현직자가 꼽은 단골(열저항 저감, 패키지 열관리)입니다. HBM은 적층 구조라 방열이 곧 제품 경쟁력입니다.
@p 왜: 성능·수명·신뢰성, 적층이라 열이 빠져나갈 길이 김
@p 방법: 열이 지나가는 길의 저항을 줄인다
@p 재료 열전도 / 수직 통로 / 두께 / 패키지 밖
@p 방열·충진성·휨이 얽혀 있음
@m 칩 온도가 오르면 **성능과 수명, 신뢰성**이 모두 나빠집니다. 특히 HBM은 칩을 여러 장 쌓기 때문에 **가운데 층의 열이 빠져나갈 길이 길고**, 바로 옆 GPU의 열도 받습니다. 적층 수가 늘수록 방열이 제품 경쟁력을 결정합니다.

방법은 **열이 지나가는 길의 저항을 줄이는 것**입니다. 칩 사이를 채우는 재료의 **열전도를 높이고**, 열이 수직으로 지나갈 **금속 통로를 늘리고**, 칩 사이 간격과 접합층 두께를 줄입니다. 패키지 밖으로는 **히트 스프레더**로 열을 넓게 퍼뜨려 냉각 장치로 넘깁니다.

다만 방열을 위해 필러를 늘리면 점도가 올라 충진이 어려워지는 것처럼, **방열과 충진성과 휨이 서로 얽혀 있어서** 하나만 최적화할 수 없다는 점이 핵심이라고 생각합니다.
@k 중요성 :: 성능|수명|신뢰성|온도
@k 적층 구조 :: 적층|가운데|쌓
@k 재료 :: 열전도|필러|재료
@k 경로 :: 통로|범프|간격|두께|저항
@k 패키지 밖 :: 히트 스프레더|냉각|TIM
@k 트레이드오프 :: 얽혀|점도|충진|트레이드
@f MR-MUF가 방열에 유리하다고 하는 이유는 무엇입니까? || 칩 사이를 채우는 EMC의 열전도가 필름 재료보다 높다고 알려져 있음. 12단 HBM3 기사에서는 방열성이 높은 신규 EMC 적용.
@f 열전도가 높은 필러를 쓰면 생기는 부작용은 무엇입니까? || 점도 상승, 충진성 저하. 아는 범위까지만.

@q 패키지 신뢰성 평가에는 어떤 것이 있습니까?
@why 현직자가 꼽은 단골(열순환·충격 등 신뢰성 테스트)입니다. 이름 나열보다 "이 시험은 어떤 고장을 보려는 것인가"를 붙여야 합니다.
@p 품질 vs 신뢰성
@p 가속 시험, JEDEC 기준
@p 환경: 프리컨디셔닝, TC, THB, HAST
@p 수명: HTOL / 기계: 낙하·진동·굽힘
@p 엔지니어의 일: 고장과 공정 요인을 연결
@m 먼저 **품질과 신뢰성을 구분**하겠습니다. 품질은 출하 시점에 기준을 만족하는지이고, 신뢰성은 그 품질이 **보증 기간 동안 유지되는지**입니다. 몇 년을 기다릴 수 없기 때문에 **가속 시험**으로 확인하고, JEDEC 규격을 기준으로 삼습니다.

패키지와 관련된 환경 시험으로는, 실장 과정의 흡습과 리플로우 열을 모사하는 **프리컨디셔닝**을 전처리로 하고, 온도를 반복해서 올리고 내려 재료 간 열팽창 차이로 생기는 **박리와 크랙, 솔더 접합부 불량**을 보는 **TC**, 고온·고습에 전압까지 걸어 부식과 내습성을 보는 **THB와 HAST**가 있습니다. 수명 쪽으로는 고온에서 동작시키는 **HTOL**이 있고, 기계적으로는 **낙하, 진동, 굽힘** 시험이 있습니다.

개발 엔지니어에게 중요한 것은 시험 이름보다 **'어떤 시험에서 어떤 고장이 났고, 그것이 어떤 공정·소재 요인과 연결되는가'**를 추적하는 것이라고 생각합니다.
@k 구분 :: 품질|신뢰성|유지
@k 가속·기준 :: 가속|JEDEC
@k 전처리 :: 프리컨디셔닝|흡습|리플로우
@k 온도 시험 :: TC|thermal|열 사이클|온도 사이클
@k 습도 시험 :: THB|HAST|고습|내습
@k 기타 :: HTOL|낙하|진동|굽힘
@f TC 시험에서 박리가 나왔다면 어떤 공정 요인을 의심하겠습니까? || 계면 접착(표면 오염·세정), EMC의 CTE·탄성률, 흡습 관리, 경화 조건.
@f HAST와 UHAST의 차이는 무엇입니까? || 전압(바이어스)을 거는지 여부. UHAST는 전압 없이 고온·고습.

@q 최근 패키징 기술 트렌드를 설명해 보세요.
@why 현직자가 꼽은 단골입니다. 뉴스 나열이 아니라 "그래서 PKG 엔지니어에게 어떤 과제가 생기는가"로 끝나야 합니다.
@p 한 문장 요약
@p 수직 적층 고도화 (HBM4, 하이브리드 본딩)
@p 이종 집적 (2.5D, 커스텀 HBM)
@p 열·휨 한계 대응
@p 본인 강점과 연결
@m 한 문장으로 **'패키지가 성능을 만드는 시대'**라고 정리하겠습니다. 세 가지 흐름이 있습니다.

첫째 **수직 적층의 고도화**입니다. HBM은 적층 단수가 계속 늘고 있고, HBM4에서는 입출력 수가 크게 늘면서 **베이스 다이에 로직 공정**이 적용됩니다. 접합은 MR-MUF를 고도화하면서 **하이브리드 본딩**을 준비하는 방향입니다.

둘째 **이종 집적**입니다. 로직과 HBM을 인터포저 위에 나란히 올리는 **2.5D 패키지**가 AI 가속기의 표준이 됐고, 고객별로 설계를 달리하는 **커스텀 HBM**도 같은 흐름입니다.

셋째 **열과 휨의 한계 대응**입니다. 칩은 얇아지고 발열은 늘어서 **고방열 소재, 휨 제어, 새로운 갭 충진 공정**이 핵심 과제가 됐습니다.

세 가지 모두 **소재와 공정을 함께 봐야 풀리는 문제**라서, 제 경험을 살릴 수 있는 영역이라고 생각합니다.
@k 요약 :: 성능|시대
@k 적층 :: HBM4|적층|하이브리드|베이스 다이
@k 이종 집적 :: 2.5D|인터포저|커스텀|이종
@k 열·휨 :: 방열|휨|갭
@k 연결 :: 소재와 공정|경험|영역
@f 그중 SK하이닉스에 가장 큰 위험이 될 변화는 무엇이라고 봅니까? || 본인 판단 + 근거. 예: 접합 방식 전환기에 기존 강점(MR-MUF)이 약해질 수 있음 → 두 방식을 함께 준비.
@f 커스텀 HBM이 늘면 PKG개발의 일은 어떻게 달라집니까? || 고객별 요구(높이·열·범프 배치)에 맞춘 평가와 고객 대응이 늘어난다.

@q HBM이 무엇인지 설명하고, SK하이닉스가 앞서 있다고 평가받는 이유를 말해 보세요.
@why 과거 후기에 "HBM의 의미"를 묻는 질문이 있습니다. 정의 → 왜 필요한가 → 왜 SK하이닉스인가 순서로.
@p 정의: TSV로 수직 연결해 대역폭을 높인 메모리
@p AI에서 왜 필요한가
@p 앞선 이유 3가지
@p 남은 과제
@m HBM은 High Bandwidth Memory, 즉 여러 장의 D램을 TSV로 수직 연결해서 **데이터가 오가는 통로 수를 크게 늘린 메모리**입니다. AI 가속기는 한 번에 많은 데이터를 주고받아야 해서 **대역폭과 전력 효율**이 중요하고, 그래서 GPU 바로 옆에 HBM을 붙여 씁니다.

SK하이닉스가 앞선 이유로는 세 가지를 꼽겠습니다. 첫째 **MR-MUF**라는 패키징 선택입니다. 방열과 생산성에 유리한 방식을 일찍 양산에 적용하고 계속 고도화했습니다. 둘째 **주요 고객과 쌓은 양산 경험**입니다. 셋째 **전공정, 후공정, 설계가 맞물리는 협업**입니다. 12단 HBM3 개발 인터뷰에서도 소자, 설계, 패키지 기술이 함께 맞물린 결과라고 설명했습니다.

다만 올해 경쟁사도 HBM4 양산 출하를 시작한 만큼, **HBM4 이후의 수율과 차세대 접합 기술**에서 격차를 유지하는 것이 과제라고 생각합니다.
@k 정의 :: TSV|수직|대역폭|통로
@k 필요성 :: AI|GPU|전력
@k 패키징 강점 :: MR-MUF|방열|생산성
@k 경험·협업 :: 고객|양산|협업
@k 과제 :: 경쟁|HBM4|수율|격차
@f HBM의 세대(HBM3E, HBM4)가 바뀌면 패키지에서 무엇이 달라집니까? || 입출력 수와 TSV 수 증가, 적층 단수 증가, 베이스 다이 변화 → 범프 미세화·휨·열 과제.
@f 일반 D램과 비교해 HBM의 수율 관리가 어려운 이유는 무엇입니까? || 여러 장을 쌓기 때문에 한 장 또는 한 접합의 불량이 전체 불량이 된다(누적 수율).

@q 칩이 얇아지면 패키지 공정에서 어떤 문제가 생깁니까?
@why 적층 단수 증가의 직접적인 결과입니다. 휨 → 핸들링 → 접합으로 이어지는 연쇄를 말할 수 있어야 합니다.
@p 휨 / 깨짐·핸들링 / 접합 불량
@p 대응: 캐리어, 휨 제어
@p 12단 HBM3 사례
@m 세 가지 문제가 커집니다. 첫째 **휨**입니다. 얇을수록 연마 후 잔류 응력만으로도 웨이퍼와 칩이 휩니다. 둘째 **핸들링과 깨짐**입니다. 절단, 픽업, 적층 과정에서 가장자리가 깨지거나 크랙이 생기기 쉽습니다. 그래서 TSV 공정에서는 캐리어에 임시로 붙여 평탄하게 잡아 줍니다. 셋째 **접합 불량**입니다. 휜 칩을 쌓으면 범프 높이가 맞지 않아 접합이 안 될 수 있습니다.

12단 HBM3에서 칩을 약 40% 얇게 만들면서 **휨 제어 기술**을 새로 적용했다는 뉴스룸 기사가 이 문제를 잘 보여 준다고 생각합니다.

@k 깨짐 :: 깨|크랙|치핑|핸들링
@k 접합 :: 접합|범프
@k 대응 :: 캐리어|제어
@k 사례 :: 12단|40%|HBM3

@q 계면 박리(Delamination)는 왜 생기고, 어떻게 막습니까?
@why 지원서에서 입사 후 해결하겠다고 쓴 문제 중 하나이고, 본인 경험(계면 접착력 분석)과 가장 잘 이어지는 질문입니다.
@p 원리: 계면 응력 > 접착 강도
@p 응력 쪽 원인: CTE 차이
@p 접착 쪽 원인: 오염, 흡습
@p 대책 두 방향 + 검증
@p 본인 경험
@m 박리는 **계면에 걸리는 응력이 접착 강도를 넘을 때** 생깁니다.

응력 쪽 원인은 재료 간 **CTE 차이**입니다. 온도가 오르내릴 때마다 계면에 응력이 반복됩니다. 접착 쪽 원인은 **표면 오염**과 **흡습**입니다. 수분이 계면에 모인 상태에서 리플로우 같은 고온을 만나면 계면이 벌어질 수 있습니다.

대책도 두 방향입니다. **응력을 줄이려면** CTE와 탄성률이 맞는 소재를 고르고 구조에서 응력이 몰리는 곳을 줄입니다. **접착을 높이려면** 표면을 세정하고, 접착 특성이 맞는 소재를 쓰고, 자재를 건조·관리합니다. 검증은 프리컨디셔닝과 TC 이후 **초음파 검사**로 합니다.

현 직장에서 **기재와 합제층의 계면 접착력이 변형에 미치는 영향**을 분석한 경험이 있어서, 계면 문제를 응력과 접착 두 축으로 보는 데 익숙합니다.
@k 원리 :: 응력|접착 강도|넘
@k 응력 원인 :: CTE|열팽창|반복
@k 접착 원인 :: 오염|흡습|수분
@k 대책 :: 소재|세정|건조|표면
@k 검증 :: 초음파|TC|프리컨디셔닝
@k 경험 :: 계면 접착력|경험|합제
@f 계면 접착력은 어떻게 측정합니까? || 본인이 현 직장에서 쓴 방법을 사실대로. 패키지 쪽 방법은 모르면 "입사 후 배우겠다".

@q 언더필의 종류(CUF, MUF, NCP, NCF)를 설명해 보세요.
@why MR-MUF와 TC-NCF의 이름이 어디서 왔는지 이해하고 있는지 확인하는 질문입니다.
@p 언더필의 역할
@p 본딩 후 채움: CUF, MUF
@p 본딩 전 도포: NCP, NCF
@p HBM의 두 방식과 연결
@m 언더필은 범프로 연결한 칩과 기판, 또는 칩과 칩 사이를 채워서 **접합부의 신뢰성을 높이는** 재료입니다. 플립 칩에서는 칩과 기판의 열팽창 차이 때문에 꼭 필요합니다.

넣는 시점으로 나누면, **본딩 후에 채우는 방식**으로 모세관 현상을 이용해 옆에서 흘려 넣는 **CUF**와, 몰딩용 EMC가 언더필 기능까지 겸하는 **MUF**가 있습니다. **본딩 전에 미리 바르는 방식**으로는 페이스트 형태의 **NCP**와 필름 형태의 **NCF**가 있습니다.

MUF는 언더필과 몰딩을 한 번에 해서 **공정이 단순**하지만 좁은 갭을 채우는 것이 과제이고, NCF는 접합과 충진을 동시에 하지만 **칩마다 열압착**이 필요합니다. HBM에서 MR-MUF와 TC-NCF가 갈리는 지점도 여기라고 이해하고 있습니다.
@k 역할 :: 접합부|신뢰성|열팽창|채워
@k 본딩 후 :: CUF|모세관|MUF
@k 본딩 전 :: NCP|NCF|필름|페이스트
@k 비교 :: 단순|열압착|갭
@k 연결 :: MR-MUF|TC-NCF|HBM
