# AI 답 검증 훈련. AI의 답에서 "그대로 쓰면 안 되는 문장"을 고르는 연습입니다. AI의 답은 훈련용으로 직접 만든 것입니다.
# @line 표시: o = 맞는 문장 / x = 틀린 문장 / q = 근거 없는 수치·단정·비약 (검증 없이 쓰면 안 됨). "::" 뒤는 해설.

@id AV1
@title 몰딩 방식 설명
@ctx 트랜스퍼 몰딩과 컴프레션 몰딩의 차이를 AI에게 물었습니다.
@line o 트랜스퍼 몰딩은 EMC 태블릿을 녹여서 통로를 따라 금형 안으로 흘려보내 채우는 방식입니다.
@line x 컴프레션 몰딩은 EMC가 더 먼 거리를 흘러야 해서, 기판이 커질수록 충진이 어려워집니다. :: 반대입니다. 컴프레션은 금형에 EMC를 미리 넣고 그 자리에서 눌러 성형하므로 흐르는 거리가 짧고, 그래서 얇은 패키지와 대형 기판에 유리합니다.
@line o 적층 수가 늘고 패키지가 얇아질수록 트랜스퍼 방식은 충진이 어려워집니다.
@line q 현재 HBM 생산 라인의 95%가 컴프레션 설비를 쓰고 있습니다. :: 출처 없는 수치입니다. 실제 라인의 설비 구성은 공개된 자료가 없습니다. 이런 수치는 출처를 되묻고, 확인할 수 없으면 쓰지 않습니다.
@say AI의 설명 중 컴프레션 몰딩의 유동 거리가 반대로 되어 있어서 뉴스룸 칼럼의 설명과 대조해 바로잡았습니다. 설비 비율 수치는 출처를 확인할 수 없어 쓰지 않았습니다.

@title MR-MUF와 TC-NCF 비교
@ctx HBM 적층 방식 두 가지를 비교해 달라고 했습니다.
@line x TC-NCF는 칩을 모두 쌓은 뒤 한 번에 리플로우해서 범프를 접합합니다. :: 뒤바뀌었습니다. 한 번에 리플로우하는 쪽이 MR-MUF이고, TC-NCF는 필름을 붙인 칩을 한 장씩 열과 압력으로 눌러 붙입니다.
@line o MR-MUF는 칩 사이를 액상 EMC로 채워 굳힙니다.
@line o 열압착 방식은 한 장씩 진행하므로 생산성이 상대적으로 낮습니다.
@line q 따라서 MR-MUF가 모든 면에서 우월하며 약점이 없습니다. :: 단정입니다. MR-MUF는 누르는 힘이 약해 얇은 칩의 휨 제어가 어렵고, 좁은 갭을 Void 없이 채우는 것이 과제입니다. 12단 HBM3에서 휨 제어 기술을 따로 넣은 이유입니다.
@say 두 방식의 설명이 서로 바뀌어 있어서 정정했고, '약점이 없다'는 결론은 받아들이지 않았습니다. 휨과 갭 충진이라는 과제를 함께 말씀드리겠습니다.

@id AV3
@title 필러 함량과 EMC 물성
@ctx 필러 함량을 높이면 어떻게 되는지 물었습니다.
@line o 실리카 필러 함량을 높이면 EMC의 열팽창계수가 낮아져 실리콘 칩과의 차이가 줄어듭니다.
@line x 필러가 늘어나면 점도가 낮아져서 좁은 갭의 충진성도 함께 좋아집니다. :: 반대입니다. 필러가 늘면 점도가 올라가 유동성이 떨어지고, 좁은 갭을 채우기 어려워져 Void 위험이 커집니다. 그래서 트레이드오프입니다.
@line o 유리전이온도(Tg)를 넘으면 열팽창이 크게 늘어납니다.
@line q 최적 필러 함량은 89%입니다. :: 조건 없는 수치 단정입니다. 최적점은 갭 크기, 필러 크기 분포, 공정 조건에 따라 달라집니다. '어떤 조건에서의 값인지'를 되물어야 합니다.
@say AI가 점도 방향을 반대로 말해서 바로잡았습니다. 최적 함량은 하나의 숫자가 아니라, 충진 한계 안에서 가장 높은 함량을 실험으로 정하는 것이라고 판단했습니다.

@title 신뢰성 시험
@ctx 패키지 신뢰성 시험을 정리해 달라고 했습니다.
@line o 온도 사이클(TC) 시험은 재료 간 열팽창 차이로 생기는 박리와 크랙을 봅니다.
@line x UHAST는 고온·고습에서 전압을 건 상태로 진행하는 시험입니다. :: 틀렸습니다. UHAST의 U는 Unbiased, 즉 전압을 걸지 않는다는 뜻입니다. 전압을 거는 시험은 THB와 HAST입니다.
@line x 프리컨디셔닝은 다른 신뢰성 시험을 모두 마친 뒤 마지막에 진행합니다. :: 틀렸습니다. 프리컨디셔닝은 흡습과 리플로우 열을 미리 겪게 하는 전처리로, 다른 환경 시험 앞에 둡니다.
@line o 품질은 출하 시점에 기준을 만족하는지, 신뢰성은 그 품질이 시간이 지나도 유지되는지를 뜻합니다.
@say 시험 이름과 조건 두 군데가 틀려 있어서 뉴스룸의 신뢰성 칼럼과 대조해 고쳤습니다. 약어는 풀어서 뜻을 확인하는 습관이 도움이 됐습니다.

@id AV5
@title 적층 수율 계산
@ctx "접합 한 번의 수율이 99%이고 접합을 16번 한다면 전체 수율은?" 하고 물었습니다.
@line o 접합이 한 번이라도 실패하면 전체가 불량이므로, 각 접합의 수율을 곱해야 합니다.
@line x 계산하면 전체 수율은 약 92%입니다. :: 계산이 틀렸습니다. 0.99를 16번 곱하면 약 0.85, 즉 85%입니다. AI는 계산을 자주 틀립니다. 숫자는 직접 다시 계산합니다.
@line q 따라서 16단까지는 수율 문제가 없습니다. :: 비약입니다. 어떤 수준이면 '문제없다'고 볼지 기준이 없습니다. 85%라면 15%가 손실이므로 오히려 큰 문제일 수 있습니다.
@line o 접합 한 번의 수율이 조금만 낮아져도 단수가 높을수록 전체 수율 차이가 크게 벌어집니다.
@say 곱해야 한다는 원리는 맞았지만 계산값이 틀려서 직접 다시 계산했고, 약 85%로 정정했습니다. '문제없다'는 결론은 기준이 없어 받아들이지 않았습니다.
@s gen

@id AV6
@title 과제 자료와 대조하기
@ctx 문제해결 PT의 과제 자료는 다음과 같습니다. 필러 최대 입경 A 5µm → B 8µm (갭 약 25µm), Void 불량률 A 0.3% → B 2.1% (칩 중앙부 집중), Tg A 150℃ → B 135℃. 이 자료를 주고 원인을 물었습니다.
@line x 소재 B의 필러 최대 입경은 12µm로 갭의 절반에 가깝습니다. :: 자료와 다릅니다. 자료에는 8µm로 되어 있습니다. AI가 주어진 수치를 바꿔 말하는 경우가 있으므로, 답에 나온 숫자는 과제 자료와 하나씩 대조합니다.
@line o 점도가 높아져 중앙부까지 채우기 전에 유동이 느려졌을 가능성이 있습니다.
@line q 원인은 진공도 부족입니다. 진공 설비를 교체하십시오. :: 근거 없는 단정입니다. 자료에는 진공 정보가 없습니다. 게다가 설비 교체는 가장 비싼 조치입니다. 가설 후보로만 남깁니다.
@line o Tg가 낮아진 것이 고온 휨 증가와 관련 있을 수 있으며, 온도별 휨 측정으로 확인할 수 있습니다.
@say AI의 답에 과제 자료와 다른 수치가 하나 있어 자료 기준으로 고쳤고, 자료에 근거가 없는 진공 원인은 가설 후보로만 남겼습니다.

@ctx 조건: 판단 회의까지 6주, 쓸 수 있는 더미 웨이퍼는 24장. 이 조건을 주고 평가 계획을 물었습니다.
@line x 온도 사이클 1,000회를 포함한 모든 신뢰성 시험을 끝낸 뒤에 판단하는 것이 안전합니다. :: 기한을 무시했습니다. 6주 안에 끝낼 수 없는 계획입니다. 중간 결과로 판단하고 남는 위험을 밝히는 방식으로 바꿔야 합니다.
@line x 변수 5개를 각각 2수준으로 한 완전 요인 실험으로 모든 조합을 확인하십시오. :: 자원을 넘었습니다. 2수준 5변수의 모든 조합은 32가지인데 웨이퍼는 24장입니다. 가설로 변수를 줄여야 합니다.
@line o 시험 기간이 긴 항목은 가장 먼저 투입해 두는 것이 좋습니다.

@say AI의 계획은 기한과 자재 수량을 넘어서 그대로 쓸 수 없었습니다. 조건 안에서 줄일 것과 남길 위험은 제가 정했습니다.

@id AV8
@title CVD와 ALD
@ctx 두 증착 방식의 차이를 물었습니다.
@line x CVD는 원료를 한 종류씩 번갈아 넣어 한 층씩 쌓는 자기 제한 반응입니다. :: 뒤바뀌었습니다. 원료를 번갈아 넣는 자기 제한 반응은 ALD입니다. CVD는 원료 기체를 함께 넣어 반응시킵니다.
@line o ALD는 깊고 좁은 구조의 안쪽까지 고르게 덮는 데 유리합니다.
@line o ALD는 한 층씩 쌓기 때문에 속도가 느립니다.
@line q 그러므로 모든 막을 ALD로 바꾸는 것이 가장 좋습니다. :: 비약입니다. 두꺼운 막을 빠르게 쌓아야 하는 곳에서는 속도와 비용 때문에 CVD가 맞습니다. 용도에 따라 고르는 것입니다.
@say 두 방식의 설명이 바뀌어 있어 정정했고, '모두 ALD로'라는 결론은 속도와 비용을 고려하지 않아 받아들이지 않았습니다.

@title 관리도 해석
@ctx 측정값 관리도를 보여 주고 공정 상태를 물었습니다. 점은 모두 관리 한계 안에 있지만 마지막 7개가 연속으로 올라가고 있습니다.
@line x 모든 점이 관리 한계 안에 있으므로 공정은 정상입니다. :: 틀렸습니다. 한계 안이라도 한쪽으로 이어지는 경향은 이상 신호입니다. 한계를 벗어나기 전에 원인을 찾는 것이 관리도의 목적입니다.
@line o 관리 한계는 공정 데이터에서 계산한 값이고, 규격 한계는 제품이 만족해야 하는 값이라 서로 다릅니다.
@line x Cpk는 산포만 반영하고 평균의 치우침은 반영하지 않습니다. :: 틀렸습니다. 산포만 보는 것은 Cp이고, Cpk는 평균이 규격 중심에서 치우친 정도까지 반영합니다.
@line o 서서히 오르는 모양은 소모품 마모나 오염 누적처럼 시간에 따라 변하는 원인을 먼저 의심하게 합니다.
@say AI는 한계 안이라 정상이라고 했지만, 연속 상승은 이상 신호라서 받아들이지 않았습니다. 상승이 시작된 시점에 바뀐 것부터 확인하겠습니다.
